# Bode VS Code Panel Skeleton

Wave 8 keeps the VS Code panel read-only and external to the CLI. The extension reads `~/.bode/scheduler.json` and shells out to `bode continue`, `bode cancel`, `bode show`, and `bode replay`.

This folder documents the contract for the future `KakunynQA/bode-vscode` repository without embedding IDE logic in the CLI package.
